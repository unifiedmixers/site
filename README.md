# unifiedmixers/site

The product page for https://unifiedmixers.org and https://www.unifiedmixers.org.

Plain static HTML — one file, no build step, no JavaScript, no external assets.
Deployed via Cloudflare Pages: a push to `main` publishes; deleting the branch
unpublishes. Keep it that way.

The footer carries the Impressum link on purpose — § 5 TMG applies the moment a
page markets something under the umbrella. Don't remove it during redesigns.
